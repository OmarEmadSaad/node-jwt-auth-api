A secure user API with JWT auth and role-based access

A REST API for registering, logging in and managing users. Short-lived access tokens, rotating refresh tokens, three permission levels, request validation and avatar/PDF uploads, all with one consistent JSON response format.

Key features

What the API does

JWT authentication

Access tokens expire after 10 minutes. Refresh tokens rotate on every use, and only the latest one is accepted, so a stolen old token is useless.

Role-based access

user can read, admin manages user accounts, and a manager manages everyone and their roles.

Secure passwords

Passwords are hashed with bcrypt, never selected by default and never sent back. Login errors don't reveal which emails exist, and attempts are rate-limited.

Two layers of validation

express-validator checks every request before it reaches a controller, and the Mongoose schema checks the data again before it's saved.

Safe file uploads

Avatars (JPG, PNG, WEBP) and PDFs up to 5 MB, named by their checked type, never by the uploaded name. Replaced, deleted or failed uploads are cleaned up.

Consistent errors

One error handler turns validation, duplicate-key, upload and auth errors into the same JSend-style JSON, with correct 400, 401, 403, 404, 405, 409 and 429 codes.

Architecture

How a request flows

Each request passes through small, single-purpose middleware, then a thin controller hands the work to a service. Any error, at any step, goes to one error handler.

API reference

Endpoints

All paths start with /api.

MethodPathAccessDescription
GET/healthPublicIs the API up and connected to the database?
POST/auth/registerPublicCreate an account (role is always user)
POST/auth/loginPublicGet an access and a refresh token
POST/auth/refreshRefresh tokenSwap the refresh token for a new pair
POST/auth/logoutLogged inRevoke the refresh token
GET/usersLogged inList all users
GET/users/:idLogged inGet one user
POST/usersAdmin, managerCreate a user (only a manager can pick the role)
PUT/users/:idAdmin, managerUpdate a user
PATCH/users/:idAdmin, managerUpdate some fields
DELETE/users/:idAdmin, managerDelete a user and their files

Admins can change or delete accounts with the user role (and their own); only a manager can change or delete admins and managers.

    Getting started

    Run it locally

    1. Install

      npm install

      Needs Node.js 22.18 or newer.

    2. Configure

      cp .env.example .env

      Fill in your MongoDB URI and two JWT secrets.

    3. Seed and test

      npm run seed
npm test

    4. Start

      npm run dev

      Then open http://localhost:3000: the API serves this page too.
